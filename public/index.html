Ephemeral Chat — minimal index.html

This repository is missing a frontend build in public/. I added this minimal index.html so the server fallback can serve a page while you deploy your app assets.

Next steps
  • Place your production build files (index.html, assets, JS bundle, etc.) under public/.
  • If you use a bundler, run your build and copy the output into public/ before deploying.
  • To see the WebSocket server in action, open the browser console and connect a client that speaks the chat protocol (type: "join", "msg").
